# 🏞️ Project_TwoStep  
> 국립공원 트래킹 맞춤 정보 제공 플랫폼

---

## 📌 프로젝트 주제

**TwoStep**은 등산을 좋아하는 사용자들에게  
**코스 난이도, 소요 시간, 실시간 날씨**의 정보를  
직관적이고 효율적으로 제공하는 **국립공원 맞춤형 트래킹 정보 플랫폼**입니다.

---

## 🗓️ 프로젝트 개요

- **수행기간**: 2025.04.16 ~ 2025.05.09  
- **수행인원**: 총 4명 (프론트엔드 3명 / 백엔드 1명)

---

## 🎯 프로젝트 동기 및 목표

- 등산 전 **코스 선택과 준비를 더 정확하고 편리하게** 하기 위한 정보를 제공하고자 시작한 프로젝트입니다.  
- **국립공원 공공데이터를 기반**으로 사용자가  
  자신의 상황(난이도, 위치, 날씨 등)에 맞는 트래킹 코스를 찾고,  
  **지도 기반 UI를 통해 시각적으로 탐색**할 수 있도록 구현했습니다.

---

## ✅ 주요 기능

- 🗺️ **지도 기반 트래킹 코스 시각화**
  - 국립공원별 마커 표시
  - 마커 클릭 시 코스 정보(거리, 소요 시간, 난이도 등) 출력

- 🔍 **코스 필터링 및 정렬 기능**
  - 난이도, 위치, 국립공원 등 기준 필터링
  - 이름/거리/시간 기준 정렬

- 🌦️ **실시간 날씨 정보 연동**
  - 각 코스 위치별 날씨 API 연결

- 👤 **관리자 기능**
  - 코스 정보 등록, 수정, 삭제
  - 데이터 관리용 관리자 전용 페이지 제공
